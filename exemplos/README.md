# Exemplos por linguagem

Programas prontos para abrir no MisterALG. Em cada linguagem (exceto Portugol) há 3 exemplos:

- `vetores` - vetor/lista com laço que calcula a soma e a média
- `fatorial` - função recursiva (fatorial de 5)
- `entrada_condicional` - lê um valor do usuário e usa um `if`/`else`

SQL tem um único script, `sql/escola.sql`, que cria as tabelas `alunos`, `disciplinas` e `matriculas` (com `REFERENCES`), insere os dados e faz 3 consultas (JOIN, GROUP BY com COUNT, ORDER BY). Ele é para PostgreSQL.

| Linguagem  | Pasta         | Arquivos |
|------------|---------------|----------|
| C          | `c/`          | `vetores.c`, `fatorial.c`, `entrada_condicional.c` |
| C++        | `cpp/`        | `vetores.cpp`, `fatorial.cpp`, `entrada_condicional.cpp` |
| C#         | `csharp/`     | `Vetores.cs`, `Fatorial.cs`, `EntradaCondicional.cs` |
| JavaScript | `javascript/` | `vetores.js`, `fatorial.js`, `entrada_condicional.js` |
| TypeScript | `typescript/` | `vetores.ts`, `fatorial.ts`, `entrada_condicional.ts` |
| Python     | `python/`     | `vetores.py`, `fatorial.py`, `entrada_condicional.py` |
| PHP        | `php/`        | `vetores.php`, `fatorial.php`, `entrada_condicional.php` |
| SQL        | `sql/`        | `escola.sql` |

Os códigos estão em inglês e os comentários são curtos, seguindo a convenção do editor para as linguagens que não são Portugol.
